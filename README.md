# Find your Magic home 🌿✨

เว็บกิจกรรม "Find your Magic home" — หน้าแรก, ลงทะเบียน, ทำแบบทดสอบ, รับบัตรประจำบ้าน (ดาวน์โหลดได้), และหน้าแอดมินสำหรับดูรายชื่อผู้ลงทะเบียนทั้งหมด

## โครงสร้างไฟล์

```
magichome/
├── server.js                 # จุดเริ่มต้นของ backend (Express)
├── package.json
├── .env.example               # คัดลอกเป็น .env แล้วตั้งรหัสผ่านแอดมิน
├── routes/
│   ├── api.js                 # API ฝั่งผู้ใช้ (ลงทะเบียน / ส่งคำตอบแบบทดสอบ)
│   ├── admin.js                # API ฝั่งแอดมิน (list / detail / export csv / login)
│   └── houseLogic.js          # คำถาม, ตัวเลือก, และตรรกะคำนวณผลว่าได้ "บ้าน" ไหน
├── middleware/
│   └── auth.js                # ป้องกันหน้า/route ที่แอดมินเท่านั้นเข้าถึงได้
├── data/
│   ├── store.js               # อ่าน/เขียนข้อมูลผู้ใช้ (ไฟล์ .json แยกรายคน)
│   └── submissions/            # ← ข้อมูลผู้ลงทะเบียนแต่ละคนจะถูกเก็บที่นี่ (1 ไฟล์ต่อ 1 คน)
├── public/                    # ← หน้าเว็บที่ "ผู้ใช้ทั่วไป" เข้าถึงได้
│   ├── index.html              # หน้าแรก (Find your Magic home)
│   ├── register.html           # ฟอร์มลงทะเบียน
│   ├── quiz.html                # แบบทดสอบ
│   ├── result.html              # ผลลัพธ์ + ดาวน์โหลดบัตร
│   ├── css/ (base, index, register, quiz, result)
│   └── js/  (fireflies, register, quiz, result)
└── admin/                     # ← หน้าเว็บที่ "แอดมินเท่านั้น" เข้าถึงได้ (ต้อง login)
    ├── login.html
    ├── dashboard.html
    └── assets/ (css, js)
```

## การเก็บข้อมูล

ทุกครั้งที่มีคนลงทะเบียน ระบบจะสร้างไฟล์ `data/submissions/<รหัสสุ่ม>.json` ให้ 1 ไฟล์ต่อ 1 คน จัดรูปแบบให้อ่านง่าย (เปิดด้วย Notepad หรือโปรแกรมอะไรก็ได้ก็อ่านออก) และเมื่อคนนั้นทำแบบทดสอบเสร็จ ไฟล์เดิมจะถูกอัปเดตให้มีคำตอบและผลลัพธ์เพิ่มเข้าไป

หน้าแอดมิน (`/admin/dashboard`) จะรวบรวมไฟล์ทั้งหมดมาแสดงเป็นตารางที่จัดเรียงเรียบร้อย พร้อมปุ่ม **"ส่งออก CSV"** ที่เปิดในโปรแกรม Excel ได้ทันที

**ผู้ใช้ทั่วไป** เข้าถึงได้แค่หน้า `/`, `/register.html`, `/quiz.html`, `/result.html` เท่านั้น — ไม่มีทางเห็นข้อมูลของคนอื่นหรือเข้าหน้าแอดมินได้ เพราะหน้า dashboard และ API `/api/admin/*` ถูกป้องกันด้วยรหัสผ่านและ session ทั้งหมด

## วิธีรันบนเครื่องตัวเอง (ทดสอบก่อนใช้จริง)

ต้องติดตั้ง [Node.js](https://nodejs.org) เวอร์ชัน 18 ขึ้นไปก่อน

```bash
cd magichome
npm install
cp .env.example .env
# แล้วแก้ ADMIN_PASSWORD และ SESSION_SECRET ในไฟล์ .env ให้เป็นค่าที่คาดเดายาก
npm start
```

เปิดเบราว์เซอร์ไปที่ `http://localhost:3000`
หน้าแอดมินอยู่ที่ `http://localhost:3000/admin/login`

เว็บนี้เป็น **Node.js + Express** ทำงานเป็นเซิร์ฟเวอร์ตลอดเวลา (ไม่ใช่เว็บ static ธรรมดา) เพราะต้องรับข้อมูลฟอร์มและเก็บไฟล์ไว้ในเครื่อง เราจึงเลือก Render.com เพราะใช้งานฟรีและใช้งานง่าย
